# Polygon PoS Mainnet Snapshot URLs
# Updated: 2026-03-06
#
# ==============================================================================
# IMPORTANT NOTES
# ==============================================================================
#
# Polygon PoS requires TWO components:
#   1. Heimdall - Consensus layer (~1.1 TB)
#   2. Bor - Execution layer (~4.9 TB for Pebble)
#
# Archive snapshots are NO LONGER supported due to unsustainable data growth.
# Only pruned/full node snapshots are available.
#
# Heimdall v2 (0.6.0) uses CometBFT/Cosmos SDK - legacy v1 is deprecated.
# Snapshot DBs go in <heimdall-home>/data/ (not the root).
# Bor with --db.engine=pebble stores chaindata at <bor-home>/bor/chaindata/.
#
# Total storage needed: ~6-8 TB recommended
#
# ==============================================================================
# OPTION 1: PUBLICNODE (Recommended - via aria2c)
# ==============================================================================

# Bor Mainnet - TWO PARTS (base + incremental):
# Part 1 (base): https://snapshots.publicnode.com/polygon-bor-base-0-75817088.tar.lz4
# Part 2 (incremental): https://snapshots.publicnode.com/polygon-bor-part-75817089-83774388.tar.lz4

# Heimdall Mainnet:
# https://snapshots.publicnode.com/polygon-heimdall-24404501-39092570.tar.lz4

# Download with aria2c (16 parallel connections, supports resume):
#   aria2c -x 16 -s 16 -d /data/rpc_nodes/polygon-data/ "https://snapshots.publicnode.com/polygon-bor-base-0-75817088.tar.lz4"
#   aria2c -x 16 -s 16 -d /data/rpc_nodes/polygon-data/ "https://snapshots.publicnode.com/polygon-bor-part-75817089-83774388.tar.lz4"
#   aria2c -x 16 -s 16 -d /data/rpc_nodes/polygon-data/ "https://snapshots.publicnode.com/polygon-heimdall-24404501-39092570.tar.lz4"

# Extract Bor (both parts to same directory):
# Tar contains bor/chaindata/ prefix, so extract to bor/ root:
#   mkdir -p /data/rpc_nodes/polygon-data/bor
#   lz4 -dc /data/rpc_nodes/polygon-data/polygon-bor-base-0-75817088.tar.lz4 | tar -xf - -C /data/rpc_nodes/polygon-data/bor
#   lz4 -dc /data/rpc_nodes/polygon-data/polygon-bor-part-75817089-83774388.tar.lz4 | tar -xf - -C /data/rpc_nodes/polygon-data/bor

# Extract Heimdall (into data/ subdirectory):
#   mkdir -p /data/rpc_nodes/polygon-data/heimdall/data
#   lz4 -dc /data/rpc_nodes/polygon-data/polygon-heimdall-24404501-39092570.tar.lz4 | tar -xf - -C /data/rpc_nodes/polygon-data/heimdall/data

# HEIMDALL V2 INIT (required before loading snapshot)

#    docker run --rm -v /data/rpc_nodes/polygon-data/heimdall:/heimdall-home:rw \
#      --entrypoint /usr/bin/heimdalld 0xpolygon/heimdall-v2:0.6.0 \
#      init my-node --chain-id=heimdallv2-137 --home=/heimdall-home

# 2. Download mainnet genesis (2.2 GB):
#    curl -L -o /data/rpc_nodes/polygon-data/heimdall/config/genesis.json \
